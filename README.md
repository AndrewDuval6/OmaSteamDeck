# OmaSteamDeck

A controller-first living-room shell for Steam Deck, inspired by Omarchy's restraint but designed as its own product.

## v0.1 prototype
- Minimal boot splash
- Multi-user profile selector
- Controller/keyboard-first home navigation
- Games, Media, Store, Library, Apps and Settings sections
- Steam Deck 1280×800 first; TV layout follows after handheld testing

## Run on Steam Deck / Omarchy
```bash
git clone https://github.com/AndrewDuval6/OmaSteamDeck.git
cd OmaSteamDeck
./run.sh
```

This first prototype does **not** repartition disks or alter the bootloader.
